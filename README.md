# Калькулятор на STM32C031

Четырёхразрядный целочисленный калькулятор на **STM32 Nucleo-C031C6**.

Ввод с матричной клавиатуры, вывод на семисегментный индикатор **TM1637**, лог операций в UART.

Проект целиком собран и проверен в Wokwi: **https://wokwi.com/projects/475335267178779649**

## Возможности

- Ввод чисел до 4 разрядов: от `-999` до `9999`
- Операции: `+`, `-`, `×`, `÷`
- Цепочка вычислений без `=`: `2 + 3 + 4` считается по мере ввода операторов
- Продолжение работы с результатом: после `=` нажатие оператора берёт результат как первый операнд
- Сброс состояния по клавише `C`
- Обработка ошибок: на индикаторе загорается `----`:
  - деление на ноль
  - переполнение
- Отрицательные результаты выводятся со знаком минус в старшем разряде

## Как это работает

### Клавиатура (`keyboard.c`)

Строки матрицы настроены как выходы с открытым стоком, столбцы — как входы с подтяжкой
к питанию. `readKey()` поочерёдно прижимает каждую строку к земле и читает `IDR`: нулевой
бит на столбце означает замкнутую кнопку на пересечении. Опрос выполняется раз в 100 тиков
SysTick. Повторная выдача события блокируется до отпускания клавиши (`lastKey`), что
работает как программный антидребезг.

### Индикатор (`tm1637.c`)

TM1637 управляется двухпроводным интерфейсом. Обмен реализован программным бит-бэнгом с задержками `delay_us()`. 

Последовательность вывода: команда данных `0x40`, команда адреса `0xC0`, 4 байта сегментов, команда яркости `0x8F`.

Коды символов лежат в таблице `digit_codes[]`, незначащие нули гасятся, `0x40` — код одиночного сегмента-минуса.

### Автомат вычислений (`main.c`)

- `ENTER_A` — набор первого операнда;
- `ENTER_B` — набор второго; нажатие нового оператора сразу применяет предыдущий;
- `RESULT` — показан итог: цифра начинает новый пример, оператор продолжает текущий.

### Вывод в UART

Функция `printf` перенаправлена через переопределённый `_write()`.

```
Pressed key: 1
Pressed key: 2
Pressed key: +
A=12, OP=+
Pressed key: 8
Pressed key: =
12 + 8 = 20
```

## Запуск

1. Открыть проект по ссылке: https://wokwi.com/projects/475335267178779649
2. Нажать ▶ (Start Simulation).
3. Нажимать клавиши на виртуальной клавиатуре, результат смотреть на индикаторе,
   подробности — в Serial Monitor.

Чтобы собрать из этого репозитория, создайте в Wokwi новый проект для
`ST Nucleo-C031C6`, замените `diagram.json` на файл из корня, а содержимое исходников —
на файлы из `src/`.
